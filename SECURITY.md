# Security Policy

## Supported Versions

We provide security maintenance for the latest code deployed on the primary branch.

| Version | Supported |
| :--- | :--- |
| `1.x` (main) | Yes |
| Earlier builds | No |

---

## Reporting a Vulnerability

If you identify a security concern, dependency vulnerability, or sensitive data exposure within this repository:

1. **Do not create a public issue.**
2. Send a detailed report directly to the repository maintainer through GitHub Security Advisories or private email.
3. Include:
   * Description of the vulnerability and affected files.
   * Reproduction steps or proof of concept.
   * Recommended remediation steps if available.

We will acknowledge receipt within 48 hours and work on a resolution promptly.
